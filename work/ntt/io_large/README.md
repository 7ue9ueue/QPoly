# io_large — I/O for convolution_mod_large (exploration 011)

Input parsing and output formatting at N, M ≤ 2^24 (2^25 tokens in, up to 2^25 − 1 values out) for
[Library Checker convolution_mod_large](https://judge.yosupo.jp/problem/convolution_mod_large). The
transform is the exploration-010 code in [../conv_large](../conv_large/README.md), unchanged.
Notes: [exploration 011](../../../notes/explorations/011-io-large.md).

## Files

| File | Role |
| --- | --- |
| [final_io_main.cpp](final_io_main.cpp) | deliverable program: 007 input mapping, `qp_parse_ms2` (128 KiB chunks), `blocks3<4>` fixed-width output, 160 KiB buffer |
| [io_main.cpp](io_main.cpp) | experiment program; macros select input (`QI_INPUT`), parser (`QI_PARSE`, `QI_CHUNK`, `QI_STREAMS`), formatter (`QI_FMT`), buffer (`QI_OBUF`) |
| [parse_ms2.inc](parse_ms2.inc) | deliverable parser: 4 lockstep streams per chunk, two tokens per stream step, flat fallback |
| [parse_ms.inc](parse_ms.inc), [parse_ms3.inc](parse_ms3.inc) | multi-stream variants (one token per step; leaner step with 4 or 8 streams) |
| [parse_tail.inc](parse_tail.inc) | tail-window parsers (needs the guarded input); no gain |
| [fmt_bcd.inc](fmt_bcd.inc) | deliverable formatter `blocks3<G>` (32-bit SWAR BCD groups) and the digit-loop reference `one()` |
| [fmt_fixed.inc](fmt_fixed.inc) | earlier fixed-width formatters (`eight()`, `blocks<G>`, scalar `one_table()`) |
| [bench_io_large.cpp](bench_io_large.cpp) | `unit [limit]`: parser and formatter checks (formatters against the reference for every value < limit, default 10^9); `time [reps]`: 2^25-token timings |
| [make_submission.py](make_submission.py) | single-file generator (inlines includes, trims the asm variants) |
| [run_io.sh](run_io.sh) | CI step: build with the judge flags, `unit`, three `time 5` runs |

Assumptions (all paths): values < 998244353 on input and output; the output contract is testlib
wcmp (tokens compared as strings), which accepts fixed 10-byte fields with space padding. The
parsers need at least 64 readable bytes after the last token's separator (the 007 input provides
a zero page or 64 bytes of heap padding); chunked parsing only starts when more than CH/2 + 64 tokens
remain, so its reads stay inside the array's text. `a[]` has 16 padding words, so formatters that
read 8G values never read past it.

## Reproduce

```bash
python3 work/ntt/io_large/make_submission.py --source final_io_main.cpp
python3 work/ntt/io_large/make_submission.py --source final_io_main.cpp --probe --out work/ntt/yosupo_convolution_mod_large_io_probe.cpp
g++ -O2 -std=c++23 -march=native work/ntt/io_large/bench_io_large.cpp -o build/bench_io_large && build/bench_io_large unit && build/bench_io_large time 5
```

CI: `.github/workflows/ntt-conv-large.yml`, plan in [../conv_large/ci.env](../conv_large/ci.env)
(`IO=1` runs `run_io.sh`; `STANDALONE`/`OFFICIAL_BUILDS` entries starting with `@io` are generated by
`make_submission.py` here).
